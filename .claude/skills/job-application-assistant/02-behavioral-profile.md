## Strongest Behaviors
- **End-to-End Ownership:** Takes features from planning through deployment and post-release support; comfortable making pragmatic technical decisions
- **Technical Communication:** Participates actively in code reviews, architectural discussions, and knowledge sharing; explains complex concepts clearly
- **Adaptability:** Comfortable in early-stage, fast-growing environments; shifts between roles (frontend, full-stack, infrastructure) based on needs
- **Initiative & Problem-Solving:** Identifies and resolves system inefficiencies; builds internal tools to automate workflows and reduce manual work

## How You Work Best
- In autonomous, self-directed environments with clear ownership of features/systems
- With collaborative cross-functional teams (product, design, QA, backend)
- On projects with visible impact and measurable outcomes
- Learning new technologies and tools as part of day-to-day work
- In remote or hybrid settings with flexible work arrangements

## Growth Areas (frame positively in applications)
- **Detail-Oriented Planning:** Developing stronger upfront project planning and estimation skills; progressing from reactive problem-solving to proactive architectural decisions
- **Mentoring at Scale:** Growing experience mentoring peers through code reviews; building capacity for more formal mentorship and team leadership roles
